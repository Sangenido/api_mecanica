# API REST - Oficina Mecânica 🚗

Este projeto é uma API REST desenvolvida em Python, seguindo a arquitetura MVC (Model-View-Controller).

## 📌 Tecnologias Utilizadas
* Python
* Flask (Framework web)
* MySQL (Banco de Dados)
* Flasgger (Swagger para documentação)

## 🗂 Estrutura do Projeto
O projeto segue o padrão MVC exigido:
* `config/` - Configuração da conexão com o banco de dados.
* `controllers/` - Controladores com as rotas da API.
* `model/` - Classes que interagem diretamente com o banco de dados.
* `venv/` - Ambiente virtual (ignorado no GitHub).
